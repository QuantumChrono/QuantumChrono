### The Deep End (Robotics, 3D & AI)
A few months ago, I got into Blender, Fusion, and UE5, which subsequently got me into robotics, real-time 3D, and AR/VR. I spent some time deep diving into hard-surface modeling and cinematic lighting in Blender (you can check out my sci-fi battery core and other models on my ArtStation).

I also like AI and recently built my own private AI platform called **Trinity**, honestly just because Jarvis fascinated me. I set up a 100% private, uncensored local AI microservice architecture. I bridged a PC and a laptop using Tailscale, separating the vision and image generation hub from the LLM inference engine. I even managed to bypass cloud limits to run a 40B parameter model across dual-T4 GPUs just to see if I could make the architecture work.

### One-Day Sprints
I like making random stuff in one day which I call "one-day sprints." Obviously, I use a lot of AI help for the syntax, but it's always me who handles the overall architecture, design, flow, and makes sure everything actually works.

*   **[Unicorpse](https://unicorpse.vercel.app)**
    A web app that brutally roasts your startup ideas based on Peter Thiel's *Zero to One*. Built to learn Next.js file structures and Groq APIs. When the API took too long, I built a mini spaceship game to collect coins while you wait.
*   **[ExportMarkdown](https://exportmarkdown.com)**
    A 100% local, client-side markdown converter. No servers, no uploads. Built mainly to learn about domains, Cloudflare hosting, and SEO optimization. Seeing my SEO score go up was honestly way more fun than getting the website ready.
*   **[Gatekeeper](https://usegatekeeper.vercel.app)**
    An AI ticket analyzer with a human approval gate and prompt-injection defense. Made in a few hours for a hackathon where we placed 4th out of 285 teams. The file structure is messy due to time constraints, but the state machine architecture works.

**Fun fact:** I'm a left-hander, but I forcefully made myself kind of ambidextrous because I thought it'd be cool to write with my right hand when my left shoulder was injured. Then I noticed my handwriting got better after a few minutes of writing. Turns out what makes you a lefty or righty is your genetic preference towards that hand. The hand wasn't better than the other when you were born, you just liked using it and got years of practice. Use the other hand and you'll just be as good due to neuroplasticity.
